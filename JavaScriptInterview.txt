Q1. What is JavaScript?
Ans.JavaScript is a scripting language used to make web pages dynamic and interactive.



Q2. Is JavaScript a compiled language or an interpreted language?
Ans. JavaScript is an interpreted language, but modern JavaScript engines also use JIT (Just-In-Time) compilation to improve performance.



Q3. What is the difference between var, let, and const in JavaScript?
Ans. var can be redeclared and reassigned. let cannot be redeclared in the same scope but can be reassigned. const cannot be redeclared or reassigned.



Q4. What is the difference between == and === in JavaScript?
Ans. == compares values and can perform type conversion, while === compares both value and data type without type conversion.



Q5. What are the different data types in JavaScript?
Ans. Primitive data types:

                String
                Number
                BigInt
                Boolean
                Undefined
                Null
                Symbol

    Non-primitive:

        Object — includes arrays, functions, and objects



Q6. What is the difference between null and undefined in JavaScript?
Ans. undefined → A variable has been declared, but no value has been assigned.
null → We intentionally assign no value to a variable.



Q7. What is hoisting in JavaScript?
Ans. Hoisting means JavaScript moves declarations to the top of their scope during the execution phase.

    // console.log(a);
    // var a = 10;



Q8. What is a function in JavaScript?
Ans. A function is a reusable block of code that performs a specific task and can be executed by calling its name.

    // function greet() {
    //     console.log("Hello");
    // }
    // 
    // greet(); // calling the function



Q9. What is the difference between a function declaration and a function expression in JavaScript?
Ans. A function declaration directly defines a function, while a function expression assigns a function to a variable.

    // //function declaration
    // function add() {
    //     return 2 + 3;
    // }
    // //Function Expression:
    // const add = function() {
    //     return 2 + 3;
    // };



Q10. Can a function declaration be called before it is defined in JavaScript?
Ans. Yes, a function declaration can be called before it is defined because function declarations are hoisted. 

    // greet();
    // 
    // function greet() {
    //     console.log("Hello");
    // }



Q11. What is an arrow function in JavaScript?
Ans. An arrow function is a shorter way to write a function using =>.

    // const add = (a, b) => a + b;



Q12. What is the difference between map() and forEach() in JavaScript?
Ans. forEach() is used to perform an operation on each array element,
map() performs an operation and returns a new array.

    // *forEach
    // let nums = [1, 2, 3];
    // nums.forEach(n => console.log(n));

    // *map
    // let nums = [1, 2, 3];
    // let result = nums.map(n => n * 2); 
    // console.log(result); // [2, 4, 6]



Q13. What is the difference between push() and pop() in JavaScript arrays?
Ans. push() adds an element to the end of an array, 
 pop() removes the last element from an array.

    // let arr = [10, 20];
    // arr.push(30); // [10, 20, 30]
    // arr.pop();    // [10, 20]



Q14. What is the difference between shift() and unshift() in JavaScript?
Ans. shift() removes the first element of an array, 
unshift() adds an element to the beginning of an array.

    // let arr = [10, 20, 30];
    // arr.shift();       // [20, 30]
    // arr.unshift(5);    // [5, 20, 30]



Q15. What is the difference between slice() and splice() in JavaScript?
Ans. slice() returns a portion of an array without changing the original array,
splice() can add, remove, or replace elements and changes the original array.

    // let arr = [10, 20, 30, 40];
    // console.log(arr.slice(1, 3));
    // // [20, 30]
    // arr.splice(1, 2);
    // // removes 20, 30
    // console.log(arr);
    // // [10, 40]



Q16. What is the difference between find() and filter() in JavaScript?
Ans. find() → returns the first element that satisfies the condition.
filter() → returns all elements that satisfy the condition in a new array.

    // let nums = [10, 20, 30, 40];
    // let a = nums.find(n => n > 20);
    // console.log(a); // 30
    // let b = nums.filter(n => n > 20);
    // console.log(b); // [30, 40]



Q17. What is a callback function in JavaScript?
Ans. A callback function is a function passed as an argument to another function, which is then called later.

    // function greet(name, callback) {
    //     console.log("Hello " + name);
    //     callback();
    // }
    // function message() {
    //     console.log("Welcome!");
    // }
    // greet("Mickey", message);



Q18. What is a closure in JavaScript?
Ans. A closure happens when an inner function remembers and can access variables from its outer function, even after the outer function has finished.

    // function outer() {
    //     let name = "Mickey";
    //     function inner() {
    //         console.log(name);
    //     }
    //     return inner;
    // }
    // let result = outer();
    // result(); // Mickey1



Q19. What is the difference between local scope and global scope in JavaScript?
Ans. Local scope means a variable can be accessed only within its defined scope, while a global variable is declared in the global scope and can generally be accessed throughout the program.

    // let x = 10; // global
    // function test() {
    //     let y = 20; // local
    //     console.log(x); // ✅
    //     console.log(y); // ✅
    // }
    // test();
    // console.log(x); // ✅
    // console.log(y); // ❌



Q20. What is the this keyword in JavaScript?
Ans. this refers to the object/context that is currently calling or executing the function. Its value depends on how the function is called.

    // const user = {
    //     name: "Mickey",
    //     showName() {
    //         console.log(this.name);
    //     }
    // }; 
    // user.showName(); // Mickey



Q21. What is the difference between call(), apply(), and bind() in JavaScript?
Ans. call() → calls the function immediately and passes arguments separately.
apply() → calls the function immediately and passes arguments as an array.
bind() → does not call immediately; it returns a new function with this fixed.

    //  function greet(city) {
    //  console.log(this.name, city);
    //  }
    //  let user = { name: "Mickey" };
    //  greet.call(user, "Delhi");
    //  greet.apply(user, ["Delhi"]);
    //  let newFunc = greet.bind(user, "Delhi");
    //  newFunc();

    call → immediately + separate arguments
    apply → immediately + array arguments
    bind → returns a new function



Q22. What is the difference between synchronous and asynchronous JavaScript?
Ans. Synchronous: JavaScript executes tasks one by one and waits for the current task to finish before moving to the next task.

Asynchronous: JavaScript can start a time-consuming task and continue executing the next task without waiting for it to finish.

    // console.log("1");
    // setTimeout(() => {
    //     console.log("2");
    // }, 2000);
    // console.log("3");



Q23. What is the event loop in JavaScript?
Ans. JavaScript is mainly single-threaded, so the event loop checks whether the call stack is empty and then moves waiting callbacks/tasks to the stack for execution.

    Call Stack → Web APIs → Queue → Event Loop → Call Stack



Q24. What is a Promise in JavaScript?
Ans. A Promise is a JavaScript object that links producing code with consuming code and represents the eventual completion or failure of an asynchronous operation.

    // let promise = new Promise((resolve, reject) => {
    //     resolve("Success");
    // });



Q25. What are the three states of a Promise in JavaScript?
Ans. Pending → Promise is still running.
     Fulfilled → Promise completed successfully.
     Rejected → Promise failed.
    // 
    // let promise = new Promise((resolve, reject) => {
    //     resolve("Success");
    // });



Q26. What is the difference between async and await in JavaScript?
Ans. async makes a function return a Promise, while await pauses the execution of that async function until a Promise is settled.

    // async function getData() {
    //     let result = await fetch("https://example.com");
    //     console.log(result);
    // }



Q27. What is the difference between setTimeout() and setInterval() in JavaScript?
Ans. setTimeout() executes a function once after a delay, while setInterval() repeatedly executes a function at a specified interval.

    // setTimeout(() => {
    //     console.log("Hello");
    // }, 2000); // runs once after 2 seconds
    // setInterval(() => {
    //     console.log("Hello");
    // }, 2000); // runs every 2 seconds



Q28. What is the difference between localStorage and sessionStorage in JavaScript?
Ans. localStorage stores data permanently until it is manually removed, while sessionStorage stores data only for the current browser session/tab.

    // localStorage.setItem("name", "Mickey");
    // sessionStorage.setItem("name", "Mickey");


Q29. What is DOM in JavaScript?
Ans. DOM stands for Document Object Model. It represents an HTML document as objects, allowing JavaScript to access and manipulate HTML elements.

    // document.getElementById("title").innerText = "Hello";



Q30. What is the difference between getElementById() and querySelector()?
Ans. getElementById() selects an element by its ID, while 
querySelector() selects the first element that matches a CSS selector.

    // document.getElementById("title");
    // document.querySelector("#title");  // ID
    // document.querySelector(".box");    // class
    // document.querySelector("p");       // first <p>



Q31. What is event bubbling in JavaScript?
Ans. Event bubbling means when an event happens on a child element, the event also travels upward to its parent elements.

    // <div id="parent">
    //     <button id="child">Click</button>
    // </div>



Q32. What is event capturing in JavaScript?
Ans. Event capturing is the process where an event travels from the outermost parent element down to the target element.

    // parent.addEventListener("click", handler, true);
