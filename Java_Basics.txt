JAVA INTERVIEW — IMPORTANT DEFINITIONS + SHORT EXAMPLES

1. JAVA BASICS

1. Java
Definition: Java is a high-level, object-oriented, class-based programming language designed to be platform independent.
Example:
class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}

2. Platform Independent
Definition: Java code can run on different operating systems because Java source code is compiled into bytecode, which runs on the JVM.
Flow:
Java Code -> Compiler -> Bytecode -> JVM -> OS

3. JVM
Definition: JVM (Java Virtual Machine) executes Java bytecode and provides platform independence.
Flow:
.class file -> JVM -> Machine Code

4. JDK
Definition: JDK (Java Development Kit) contains tools required to develop and run Java programs.
JDK = JRE + Development Tools

5. JRE
Definition: JRE (Java Runtime Environment) provides the environment required to run Java applications.
JRE = JVM + Libraries

6. Bytecode
Definition: Bytecode is the intermediate code generated by the Java compiler and stored in .class files.
Example:
javac Main.java
Produces:
Main.class


2. VARIABLES AND DATA TYPES

7. Variable
Definition: A variable is a named memory location used to store data.
Example:
int age = 20;

8. Primitive Data Type
Definition: Primitive types store simple values directly.
Example:
int age = 20;
double salary = 50000.5;
boolean active = true;

8 primitive types:
byte, short, int, long, float, double, char, boolean

9. Reference Data Type
Definition: A reference variable stores a reference to an object.
Example:
String name = "Vineet";

10. Type Casting
Definition: Converting one data type into another.
Example:
double x = 10.5;
int y = (int)x;


3. OOP CONCEPTS

11. Class
Definition: A class is a blueprint/template used to create objects.
Example:
class Student {
    String name;
    int age;
}

12. Object
Definition: An object is an instance of a class.
Example:
Student s = new Student();

13. Encapsulation
Definition: Encapsulation is wrapping data and methods together in a class and controlling access to the data.
Example:
class Student {
    private int age;

    public void setAge(int age) {
        this.age = age;
    }

    public int getAge() {
        return age;
    }
}

14. Abstraction
Definition: Abstraction means hiding implementation details and exposing only necessary functionality.
Example:
abstract class Animal {
    abstract void sound();
}

15. Inheritance
Definition: Inheritance allows one class to acquire properties and methods of another class.
Example:
class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
}

16. Polymorphism
Definition: Polymorphism means one interface/name can have multiple forms.
Types:
Compile-time -> Method Overloading
Runtime -> Method Overriding

Example:
class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}

17. Method Overloading
Definition: Defining multiple methods with the same name but different parameter lists.
Example:
void print(int x) {}
void print(String x) {}

18. Method Overriding
Definition: Providing a new implementation of a parent class method in the child class.
Example:
class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Bark");
    }
}

19. Dynamic Method Dispatch
Definition: When an overridden method is selected at runtime based on the actual object.
Example:
Animal a = new Dog();
a.sound();
Output:
Bark

20. Association
Definition: Association represents a relationship between two independent objects.
Example:
class Teacher {}
class Student {}
A teacher and student can exist independently.

21. Aggregation
Definition: Aggregation represents a weak "has-a" relationship where the contained object can exist independently.
Example:
class Department {
    Teacher teacher;
}

22. Composition
Definition: Composition represents a strong "has-a" relationship where the contained object's lifecycle depends on the container.
Example:
class Car {
    private Engine engine = new Engine();
}


4. CONSTRUCTORS

23. Constructor
Definition: A constructor is a special member used to initialize an object.
Example:
class Student {
    Student() {
        System.out.println("Constructor");
    }
}

24. Default Constructor
Definition: A constructor automatically provided by the compiler when no constructor is explicitly declared.
Example:
class Student {
}

25. Parameterized Constructor
Definition: A constructor that accepts parameters.
Example:
Student(String name) {
    this.name = name;
}

26. Constructor Overloading
Definition: Having multiple constructors with different parameter lists.
Example:
Student() {}
Student(String name) {}
Student(String name, int age) {}


5. THIS AND SUPER

27. this
Definition: this refers to the current object.
Example:
class Student {
    int age;

    Student(int age) {
        this.age = age;
    }
}

28. super
Definition: super refers to the immediate parent class object/member.
Example:
class Animal {
    String name = "Animal";
}

class Dog extends Animal {
    String name = "Dog";

    void show() {
        System.out.println(super.name);
    }
}


6. ACCESS MODIFIERS

29. Access Modifier
Definition: Access modifiers control the visibility/accessibility of classes, methods and variables.

private:
Same Class: Yes
Same Package: No
Child Class: No
Everywhere: No

default:
Same Class: Yes
Same Package: Yes
Child Class: No*
Everywhere: No

protected:
Same Class: Yes
Same Package: Yes
Child Class: Yes
Everywhere: No

public:
Same Class: Yes
Same Package: Yes
Child Class: Yes
Everywhere: Yes

30. private
Definition: Accessible only inside the same class.
Example:
private int age;

31. protected
Definition: Accessible within the same package and in subclasses.
Example:
protected int age;

32. public
Definition: Accessible from anywhere where the class itself is accessible.
Example:
public void display() {}

33. Default Access
Definition: If no access modifier is specified, package-private/default access is used.
Example:
int age;


7. STATIC, FINAL, FINALLY, FINALIZE

34. static
Definition: static makes a member belong to the class rather than individual objects.
Example:
class Student {
    static String college = "KIPM";
}

35. Static Variable
Definition: A variable shared among objects of the class.
Example:
static int count = 0;

36. Static Method
Definition: A method that belongs to the class rather than an object.
Example:
static void show() {
    System.out.println("Hello");
}
Call:
Student.show();

37. final
Definition: final prevents modification/extension depending on where it is used.
Example:
final int x = 10;

38. Final Class
Definition: A final class cannot be inherited.
Example:
final class A {}

39. Final Method
Definition: A final method cannot be overridden.
Example:
final void show() {}

40. finally
Definition: finally is a block generally used for cleanup code and executes after try/catch processing.
Example:
try {
    int x = 10 / 0;
} catch (Exception e) {
    System.out.println("Error");
} finally {
    System.out.println("Done");
}

41. finalize()
Definition: An old object-finalization mechanism associated with garbage collection. It is deprecated and should not be used in modern Java.


8. ABSTRACT CLASS AND INTERFACE

42. Abstract Class
Definition: A class declared with abstract that may contain abstract and concrete methods.
Example:
abstract class Animal {
    abstract void sound();

    void eat() {
        System.out.println("Eating");
    }
}

43. Abstract Method
Definition: A method declared without an implementation.
Example:
abstract void sound();

44. Interface
Definition: An interface defines a contract that implementing classes agree to follow.
Example:
interface Animal {
    void sound();
}

class Dog implements Animal {
    public void sound() {
        System.out.println("Bark");
    }
}

45. Functional Interface
Definition: An interface containing exactly one abstract method.
Example:
@FunctionalInterface
interface Calculator {
    int add(int a, int b);
}

46. Marker Interface
Definition: An interface with no abstract methods, used to provide metadata/capability.
Example:
class Student implements Serializable {
}


9. STRING

47. String
Definition: String is an immutable sequence of characters.
Example:
String name = "Vineet";

48. String Immutability
Definition: Once a String object is created, its contents cannot be changed.
Example:
String s = "Hello";
s.concat(" Java");
System.out.println(s);
Output:
Hello

49. String Pool
Definition: String Pool is a special memory area where Java stores interned string literals to reuse them.
Example:
String a = "Java";
String b = "Java";
System.out.println(a == b);
Output:
true

50. StringBuilder
Definition: StringBuilder is a mutable character sequence designed for efficient string modification.
Example:
StringBuilder sb = new StringBuilder("Java");
sb.append(" Programming");
System.out.println(sb);

51. StringBuffer
Definition: StringBuffer is a mutable and synchronized character sequence.
Example:
StringBuffer sb = new StringBuffer("Java");
sb.append(" Programming");


10. EXCEPTION HANDLING

52. Exception
Definition: An exception is an event that disrupts the normal flow of program execution.
Example:
int x = 10 / 0;

53. Exception Handling
Definition: Mechanism for handling runtime problems so the program can respond gracefully.
Example:
try {
    int x = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero");
}

54. Checked Exception
Definition: Exceptions checked by the compiler.
Examples:
IOException
SQLException

55. Unchecked Exception
Definition: Runtime exceptions that are not checked by the compiler.
Examples:
NullPointerException
ArithmeticException
ArrayIndexOutOfBoundsException

56. try
Definition: Block containing code that may throw an exception.
Example:
try {
    int x = 10 / 0;
}

57. catch
Definition: Block used to handle an exception.
Example:
catch (ArithmeticException e) {
    System.out.println("Error");
}

58. throw
Definition: Used to explicitly throw an exception.
Example:
throw new ArithmeticException("Invalid operation");

59. throws
Definition: Declares that a method may throw specified exceptions.
Example:
void read() throws IOException {
}


11. COLLECTIONS FRAMEWORK

60. Collection
Definition: A framework that provides classes and interfaces for storing and manipulating groups of objects.
Example:
List<Integer> list = new ArrayList<>();

61. List
Definition: An ordered collection that generally allows duplicate elements.
Example:
List<Integer> list = new ArrayList<>();
list.add(10);
list.add(10);

62. ArrayList
Definition: A resizable-array implementation of the List interface.
Example:
ArrayList<Integer> list = new ArrayList<>();
list.add(10);
list.add(20);

63. LinkedList
Definition: A List implementation based on linked nodes.
Example:
LinkedList<Integer> list = new LinkedList<>();
list.add(10);

64. Set
Definition: A collection that does not allow duplicate elements.
Example:
Set<Integer> set = new HashSet<>();
set.add(10);
set.add(10);

65. HashSet
Definition: A Set implementation that uses hashing and does not guarantee iteration order.
Example:
HashSet<Integer> set = new HashSet<>();
set.add(10);
set.add(20);

66. LinkedHashSet
Definition: A Set that maintains insertion order.
Example:
LinkedHashSet<Integer> set = new LinkedHashSet<>();

67. TreeSet
Definition: A sorted Set implementation.
Example:
TreeSet<Integer> set = new TreeSet<>();
set.add(30);
set.add(10);
set.add(20);
Result:
10 20 30

68. Map
Definition: A collection that stores data as key-value pairs.
Example:
Map<Integer, String> map = new HashMap<>();
map.put(1, "Vineet");

69. HashMap
Definition: A Map implementation that stores key-value pairs using hashing.
Example:
HashMap<Integer, String> map = new HashMap<>();
map.put(1, "Java");

70. LinkedHashMap
Definition: A Map implementation that maintains insertion order.
Example:
LinkedHashMap<Integer, String> map = new LinkedHashMap<>();

71. TreeMap
Definition: A Map implementation that maintains keys in sorted order.
Example:
TreeMap<Integer, String> map = new TreeMap<>();
map.put(3, "C");
map.put(1, "A");


12. ITERATOR AND COMPARABLE/COMPARATOR

72. Iterator
Definition: An object used to traverse collection elements one by one.
Example:
Iterator<Integer> it = list.iterator();

while (it.hasNext()) {
    System.out.println(it.next());
}

73. ListIterator
Definition: An iterator specifically for Lists that can traverse in both forward and backward directions.
Example:
ListIterator<Integer> it = list.listIterator();

74. Comparable
Definition: Comparable defines the natural ordering of objects through compareTo().
Example:
class Student implements Comparable<Student> {
    int age;

    public int compareTo(Student s) {
        return this.age - s.age;
    }
}

75. Comparator
Definition: Comparator defines custom ordering outside the class through compare().
Example:
Comparator<Student> c =
    (a, b) -> a.age - b.age;


13. GENERICS

76. Generics
Definition: Generics provide compile-time type safety for classes, interfaces and methods.
Example:
List<String> names = new ArrayList<>();
names.add("Vineet");

77. Generic Class
Definition: A class that works with a type parameter.
Example:
class Box<T> {
    T value;
}
Usage:
Box<Integer> b = new Box<>();

78. Wildcard
Definition: ? represents an unknown type.
Example:
List<?> list;


14. WRAPPER CLASSES

79. Wrapper Class
Definition: Wrapper classes provide object representations of primitive types.
Example:
int x = 10;
Integer y = x;

Examples:
int -> Integer
char -> Character
double -> Double
boolean -> Boolean

80. Autoboxing
Definition: Automatic conversion from primitive to wrapper object.
Example:
Integer x = 10;

81. Unboxing
Definition: Automatic conversion from wrapper object to primitive.
Example:
Integer x = 10;
int y = x;


15. MEMORY MANAGEMENT

82. Stack
Definition: Stack memory stores method call information, local variables and references associated with method execution.
Example:
void test() {
    int x = 10;
}

83. Heap
Definition: Heap memory stores objects and arrays.
Example:
Student s = new Student();

84. Garbage Collection
Definition: Garbage collection automatically identifies and reclaims memory occupied by objects that are no longer reachable.
Example:
Student s = new Student();
s = null;
The object may subsequently become eligible for GC.

85. Memory Leak
Definition: A memory leak occurs when memory that is no longer logically needed remains reachable and therefore cannot be reclaimed.


16. JVM INTERNALS

86. ClassLoader
Definition: ClassLoader loads Java class files into JVM memory when required.
Flow:
.class -> ClassLoader -> JVM

87. Method Area
Definition: JVM runtime memory area that stores class-level information such as class metadata and method information.

88. Heap
Definition: Stores objects.

89. JVM Stack
Definition: Stores stack frames for method execution.

90. Program Counter Register
Definition: Stores the address of the currently executing JVM instruction for each thread.

91. Native Method Stack
Definition: Supports execution of native methods.


17. JAVA 8+

92. Lambda Expression
Definition: A lambda expression is a concise way to represent function-like behavior.
Example:
(a, b) -> a + b

93. Functional Interface
Definition: An interface containing exactly one abstract method.
Example:
@FunctionalInterface
interface A {
    void show();
}

94. Stream
Definition: A Stream is a sequence of elements supporting functional-style operations for processing data.
Example:
List<Integer> nums = List.of(1, 2, 3, 4);

nums.stream()
    .filter(x -> x % 2 == 0)
    .forEach(System.out::println);

Output:
2
4

95. filter()
Definition: Selects elements satisfying a condition.
Example:
stream.filter(x -> x > 10);

96. map()
Definition: Transforms each element into another value.
Example:
stream.map(x -> x * 2);

97. reduce()
Definition: Combines stream elements into a single result.
Example:
int sum = List.of(1, 2, 3)
        .stream()
        .reduce(0, Integer::sum);

98. Optional
Definition: Optional is a container that may or may not contain a non-null value.
Example:
Optional<String> name =
    Optional.of("Vineet");


18. METHOD REFERENCE

99. Method Reference
Definition: A method reference is a shorthand for a lambda expression that calls an existing method.
Example:
list.forEach(System.out::println);

Equivalent:
list.forEach(x -> System.out.println(x));


19. MULTITHREADING

100. Thread
Definition: A thread is a lightweight unit of execution within a process.
Example:
Thread t = new Thread(() -> {
    System.out.println("Running");
});
t.start();

101. Multithreading
Definition: Executing multiple threads concurrently within a program.

102. Process
Definition: A process is an independent program execution environment with its own resources.

103. Thread Lifecycle
Common states:
NEW
RUNNABLE
BLOCKED
WAITING
TIMED_WAITING
TERMINATED

104. Synchronization
Definition: Synchronization controls concurrent access to shared resources.
Example:
synchronized void increment() {
    count++;
}

105. Race Condition
Definition: A race condition occurs when the result depends on the timing/order of concurrent thread execution.

106. Deadlock
Definition: Deadlock occurs when threads wait indefinitely for resources held by each other.
Example:
Thread A -> waits for B
Thread B -> waits for A

107. volatile
Definition: volatile tells the JVM that reads/writes of a variable should observe the variable's current value across threads.
Example:
volatile boolean running = true;

108. ExecutorService
Definition: ExecutorService provides a framework for managing and executing tasks using threads.
Example:
ExecutorService service =
    Executors.newFixedThreadPool(2);

service.submit(() -> System.out.println("Task"));


20. SERIALIZATION

109. Serialization
Definition: Serialization converts an object's state into a byte stream so it can be stored or transmitted.
Example:
class Student implements Serializable {
    int age;
}

110. Deserialization
Definition: Deserialization converts a byte stream back into an object.
Example:
ObjectInputStream in =
    new ObjectInputStream(inputStream);

Student s = (Student) in.readObject();

111. transient
Definition: transient prevents a field from being included in default Java serialization.
Example:
transient String password;


21. IMPORTANT JAVA KEYWORDS

112. extends
Definition: Used for class inheritance.
Example:
class Dog extends Animal {}

113. implements
Definition: Used when a class implements an interface.
Example:
class Dog implements Animal {}

114. instanceof
Definition: Checks whether an object is an instance of a particular type.
Example:
if (dog instanceof Dog) {
    System.out.println("Dog");
}

115. import
Definition: Used to access classes from another package.
Example:
import java.util.ArrayList;

116. package
Definition: Defines the package of a class.
Example:
package com.example;

117. new
Definition: Creates an object.
Example:
Student s = new Student();


22. IMPORTANT CONCEPTS INTERVIEWERS ASK DIRECTLY

118. Pass by Value
Definition: Java is strictly pass-by-value. For object variables, the value passed is a copy of the object reference.
Example:
void change(Student s) {
    s.name = "Rahul";
}

119. Immutable Object
Definition: An immutable object's state cannot be changed after creation.
Example:
String s = "Java";

120. Mutable Object
Definition: An object's state can be modified after creation.
Example:
StringBuilder sb = new StringBuilder("Java");
sb.append("!");

121. Coupling
Definition: Coupling represents the degree of dependency between classes.
Example:
class A {
    B b;
}

122. Cohesion
Definition: Cohesion represents how closely related the responsibilities of a class/module are.
A class focused on one responsibility generally has higher cohesion.

123. SOLID
Definition: SOLID is a group of five principles for designing maintainable object-oriented software.
S -> Single Responsibility
O -> Open/Closed
L -> Liskov Substitution
I -> Interface Segregation
D -> Dependency Inversion

INTERVIEW PREPARATION TIP

Do not just memorize definitions. Interviewers commonly follow a definition with:
- Why?
- How?
- Difference between?
- What happens internally?
- Give an example.
- What are the advantages/disadvantages?

Example:
Interviewer: What is HashMap?
Answer: HashMap stores key-value pairs using hashing.

Possible follow-up questions:
- How does HashMap work internally?
- What happens when two keys have the same hash?
- What is a collision?
- Why are equals() and hashCode() important?
- What changed in Java 8 HashMap?

Best preparation pattern:
Definition -> Simple Example -> Difference -> Internal Working -> Interview Questions
